# Protocole de photos pour la 3D (faisable dès maintenant avec le POCO)

1. **Consentement** : personne adulte, autorisation écrite d'utiliser son apparence pour un personnage 3D (date, usage, retrait possible). Conservée hors de GitHub.
2. **Séance** : lumière diffuse uniforme (ciel couvert ou pièce claire), fond neutre, pas de lunettes, cheveux dégagés des oreilles, expression neutre, yeux ouverts.
3. **Tour de tête** : 3 hauteurs (sous le menton, à hauteur des yeux, au-dessus), une photo tous les ≈ 15° sur 360°, soit 60 à 75 photos. Le sujet ne bouge pas ; c'est le photographe qui tourne. Mise au point sur les yeux, pas de flou.
4. **Compléments** : face, profils gauche et droit, trois-quarts, dos de la tête, sourire (pour la revue de fidélité).
5. **Import** dans PERSONA IA (Références) : classer les vues, cocher « classement vérifié ». Le rapport de couverture indique ce qui manque. Rien n'est inventé.
6. **Transfert vers le futur PC** : export volontaire (câble USB ou carte) ; **jamais** via GitHub ni un service cloud.

Les essais de développement se font uniquement avec des sujets **fictifs** (personnage MetaHuman preset ou rendu de synthèse).
