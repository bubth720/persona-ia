# PERSONA IA — Autonomous components M4–M6

Python 3.10+ standard-library-only, no network, inference, or user-media modification.

Components: model manifest and integrity; atomic JSON; thermal and RAM policy; persistent job states; reference coverage from provided metadata; video planning; output provenance.

Run tests: `python3 -m unittest discover -s independent/m4_m6/tests -v` from repository root.

These are **portable business-logic prototypes**, not an Android APK. Kotlin adaptation or an approved Python bridge and integration tests are required. No photo/video generation engine is included.
